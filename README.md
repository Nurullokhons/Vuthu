# Вуду для Android

Минимальное Android-приложение с одним переключателем состояния омовения.

## Что умеет
- Переключает два состояния: «Омовение есть» / «Омовения нет».
- Показывает состояние в постоянном уведомлении с одной кнопкой действия.
- Сохраняет состояние локально на телефоне.
- Восстанавливает уведомление после перезагрузки устройства.
- Работает без интернета, аккаунта и рекламы.

## Сборка APK
Требуется Android Studio (или Android SDK + Gradle), JDK 17 и Android SDK Platform 35.
1. Открой папку `Vudu` в Android Studio.
2. Дождись синхронизации Gradle.
3. Выбери Build → Build Bundle(s) / APK(s) → Build APK(s).
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка
Установи APK на телефон и разреши приложению отправлять уведомления. На Realme/Oppo/OnePlus проверь, что для Вуду разрешены уведомления и не включено агрессивное ограничение фоновой работы.

## Важное ограничение Android
Android и оболочки производителей сами управляют отображением уведомлений. Приложение помечает уведомление как постоянное, но некоторые версии ColorOS/Realme UI/OxygenOS могут позволять скрыть его или ограничивать восстановление после перезагрузки. Если уведомление пропало, открой приложение один раз.
