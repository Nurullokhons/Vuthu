# Как собрать APK без Android Studio

Самый безопасный простой вариант для этого проекта — GitHub Actions: сборка запускается на серверах GitHub. Android Studio на компьютере не нужна.

1. Создайте аккаунт на https://github.com (если его ещё нет).
2. Создайте новый приватный репозиторий, например `vudu-android`.
3. Распакуйте этот ZIP на компьютере. Загрузите в репозиторий **содержимое папки Vudu**, включая скрытую папку `.github`.
4. Откройте репозиторий на GitHub → вкладка **Actions**.
5. Если GitHub предложит включить Actions, подтвердите.
6. В списке workflows выберите **Build Vudu APK** → **Run workflow** → **Run workflow**.
7. Дождитесь зелёного статуса. Откройте завершённый запуск, внизу найдите **Artifacts** → `Vudu-debug-APK` и скачайте ZIP.
8. Распакуйте скачанный ZIP. Внутри будет `app-debug.apk`. Перенесите APK на телефон и установите.

Если вкладки Actions нет, откройте Settings → Actions → General и разрешите Actions для репозитория.

Примечание: это debug APK для личной установки и проверки, не публикационный релиз. Перед установкой Android может попросить разрешить установку приложений из выбранного источника.
